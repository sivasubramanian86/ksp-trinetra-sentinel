# Syndicate Graph ML Skill

This skill builds and traverses multi-modal directed crime syndicate graphs using NetworkX.

## Features

- **Entity Linking**: Vehicles, IMEIs, IMSIs, Suspects, UPI Mule Accounts, and FIR Case files.
- **Multi-Hop Traversal**: Extracting subgraphs up to N hops.
- **Syndicate Risk Scoring**: Financial velocity and shared identifier risk scoring.
